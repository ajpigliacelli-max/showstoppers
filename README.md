# Resident program modules — The Bristal at Sayville

Three browser modules for 45-minute resident programming. They run from a link,
need nothing installed, and play their clips in the page.

### Showstoppers! — musical movies game
https://htmlpreview.github.io/?https://raw.githubusercontent.com/ajpigliacelli-max/showstoppers/main/index.html

Five games plus a head-to-head duel, a 61-clip library, a persistent scoreboard
and 25 sourced intermission facts. Presenter notes hide by default so the screen
can face the room.

### That Scene! — iconic movie moments
https://htmlpreview.github.io/?https://raw.githubusercontent.com/ajpigliacelli-max/showstoppers/main/thatscene.html

Five clip reels with four games between them, built to run 45 minutes with a
presenter and a mic. A 60-second shout-out timer with ticking and a buzzer, a
four-table scoreboard, and 19 clips across twists, romance, famous lines, chases
and musical finales. Presenter notes and setup fields hide in Audience Mode so
the screen can face the room.

Unlike the two modules above, its clips ship as YouTube search buttons rather
than pre-checked embeds. Paste a clip's link into its field once during prep and
the module plays it inline from then on, saved in the browser.

### The Laugh Track — classic TV montage
https://htmlpreview.github.io/?https://raw.githubusercontent.com/ajpigliacelli-max/showstoppers/main/laughtrack.html

Ten classic TV scenes back to back, about 46 minutes, advancing on their own.
I Love Lucy, The Honeymooners, Carol Burnett, Johnny Carson, Mary Tyler Moore,
Andy Griffith, All in the Family — plus eight spares to swap in.

Every clip in both modules was checked live: the video resolves and its owner
allows embedding. Clips are embedded, never copied — they play from their
original uploads.

- `index.html` — Showstoppers!
- `laughtrack.html` — The Laugh Track
- `thatscene.html` — That Scene!
- `Showstoppers-Presenter-Guide.pdf` — printable guide book for Showstoppers!
- `That-Scene-Presenter-Guide.pdf` — printable guide book for That Scene!
