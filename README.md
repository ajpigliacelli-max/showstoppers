# Showstoppers!

A musical-movies game module for resident programming at The Bristal at Sayville.

**Play it here:** https://ajpigliacelli-max.github.io/showstoppers/

Five games plus a head-to-head duel, a 61-clip library of classic movie musical
numbers, a persistent scoreboard, and 25 sourced intermission facts. Built to fill
a 45-minute session and to be run again without repeating itself.

- `index.html` — the module (open the link above, or this file in a browser)
- `Showstoppers-Presenter-Guide.pdf` — the printable presenter guide book
